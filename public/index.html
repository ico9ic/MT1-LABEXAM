Part A — Native HTTP

Built-in HTTP Module

Created using http.createServer() on port 3000. Handles native routing, HTTP methods (GET, POST), and static file delivery via the FS module without third-party frameworks.

Part A — FS Module

Static File Serving

Uses Node.js fs.promises to read and stream this HTML document when /home is requested, setting the Content-Type: text/html response header.

Part B — Express.js

Express REST API

Runs on port 4000 providing complete CRUD endpoints: GET /cart, GET /cart/:id, POST /cart, PUT /cart/:id, and DELETE /cart/:id with JSON payloads.

⚡ Server Routes Quick Reference

HTTP Server (Port 3000):

• GET / → Welcome message in HTML format

• GET /cart → List of cart items in JSON

• GET /about → Application information

• GET /home → Serves this HTML page using FS module

• POST /add-to-cart → Add product JSON with id, productName, price, quantity
